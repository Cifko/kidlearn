TASK:
Write a multiple-choice quiz about LESSON (within SUBJECT): between MIN_QUESTIONS and MAX_QUESTIONS questions.
Question text, title, and all student-facing strings must be in {language}. Asset descriptions must be in English.
Each question is either "multiple_choice_image" (picture options) or "multiple_choice_text" (word/number options).

AUDIENCE:
- A young child (grade 1-2, early reader): very short sentences, familiar words, learns through pictures; text options only for single words or numbers.
- An older child (grade 3-4): short clear sentences; pictures for visual topics, words and numbers for abstract ones.
- An older student (high school, university, or adult): precise terminology of the field, no simplified baby talk, challenging but fair distractors that target common misconceptions; default to text unless the skill is visual.
- A general student of unknown age: assume a fluent reader; default to TEXT for abstract topics and use images only when the skill is impossible to test in words. When in doubt, text.

HARD RULES:
1. Return ONLY valid JSON matching the schema below. No explanation, no markdown, no extra text.
2. Exactly one correct answer per question; the correct option must be listed among the options.
3. ONE QUESTION, ONE KIND: never mix images and text within one question. Image questions fill options_asset_ids/correct_asset_id and leave options_text empty; text questions do the reverse.
4. All options in one question must be the SAME kind of thing and differ ONLY in the tested attribute: the same object in different counts, colors, or shapes; all numbers; all names. Never mixed.
5. Every question must test the LESSON skill directly: a student who has not learned it must NOT answer from the option names alone.
6. The question text must name ONE findable target ("Which picture shows 4 apples?", "What is 3 + 4?", "Which limit equals 0?"). "How many X?" is FORBIDDEN in image questions: with no reference picture the student must guess.
7. "Find the X" is FORBIDDEN unless the lesson is about recognizing or naming that thing.
8. Each question carries a "focus" field: one short English phrase naming the exact skill tested (e.g. "count to 12", "apply the chain rule"). If you cannot name it, rewrite the question.
9. Every referenced asset id must be defined in "assets" with a unique lowercase id and a precise visual description. Define assets first, then build questions only from them. Text questions need assets only for an optional figure.
10. If MODALITY is "text only": every question MUST be multiple_choice_text with figure_asset_id empty. No images, no exceptions.
11. If a question refers to a specific figure the student must look at (diagram, map, graph, scene), set figure_asset_id to an asset showing exactly that figure and refer to it ("in the picture"). Most questions need no figure: leave it empty rather than decorating. Never ask about a figure you did not attach.
